# 📊 Análise de Vendas | Pipeline de Dados + Power BI

Projeto completo de análise de dados com pipeline em Python, integração com SQL Server e visualização no Power BI.
![Dashboard](dashboard.png)

---

## 🚀 Tecnologias utilizadas

* Python (Pandas)
* SQL Server
* Power BI
* PyODBC

---

## 📁 Estrutura do projeto

* Extração de dados CSV
* Tratamento e limpeza com Python
* Carga em banco de dados SQL Server
* Visualização com dashboard interativo no Power BI

---

## ⚙️ Pipeline de dados

1. Extração dos dados (CSV)
2. Tratamento e limpeza
3. Transformação de colunas
4. Carga no banco de dados
5. Visualização no Power BI

---

## 📊 Dashboard

O dashboard apresenta:

* Receita total
* Total de pedidos
* Ticket médio
* Vendas ao longo do tempo
* Análise por categoria
* Análise por região
* Top produtos

---

## 🧠 Insights

* Crescimento consistente após 2016
* Categoria de tecnologia lidera as vendas
* Região West concentra maior faturamento

---

## ▶️ Como executar

1. Clone o repositório
2. Instale as dependências:

```
pip install -r requirements.txt
```

3. Configure o SQL Server no arquivo `config.py`
4. Execute:

```
python main.py
```
